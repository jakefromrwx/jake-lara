# Jake Lara

A personal landing page for Jake Lara, founder of Reworx in Lander, Wyoming. It introduces his practice: systems that fit how an organization already works, and change management that stays with the rollout.

All of the words live in `src/content/site.ts`.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on port 4317. `npm run build` produces a production build, and `npm run start` serves it.

## Contact links

The page links to `jake@reworx307.com`, LinkedIn, GitHub, and Reworx. There is no form and no backend.
